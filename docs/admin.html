Вход

Задаётся вами в секретах серверной части. Это не API-ключ провайдера. Пароль хранится только в памяти страницы до выхода или обновления.

Первый запуск: создать секреты сервера

Создайте две случайные строки и сохраните их у себя. Добавьте их в Cloudflare Worker → Settings → Variables and Secrets как Secret. Не размещайте их в GitHub. Не заменяйте ENCRYPTION_KEY после сохранения API-ключей: они перестанут расшифровываться.

Эти строки пока никуда не отправлены. Скопируйте их в секреты Worker и сохраните в менеджере паролей.

Подключения

Можно сохранить до 8 подключений. Выбор действует для всех новых запросов студентов.

Новое подключение

Текстовая модель с поддержкой системных инструкций. Название модели и ключ должны принадлежать выбранному провайдеру.

После сохранения ключ не отображается и не возвращается браузеру.

Проверить выбранный ИИ

Тест не меняет ИИ в студенческом чате. Использует настоящий API и учитывается в общем дневном лимите.

Доступ и лимиты

Один вопрос обычно вызывает два обращения к ИИ: проверку темы и ответ. Лимит ограничивает количество вопросов, а не сумму в рублях. В Wi-Fi университета общий IP, поэтому лимит сети делится между пользователями. Сутки считаются по UTC.
